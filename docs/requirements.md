## 1. 目标

GeoBoard 是一个 Windows 桌面端的动态几何画板：用户在画布上作图并施加几何约束（中点、垂直、平行、角平分、交点等），拖动任一自由点时，所有依赖它的图形与测量值按几何关系自动重算并立即重绘，从而把静态图形变成可演示、可验证的动态图形。

## 2. 使用场景

| 使用者 | 场景 | 用 GeoBoard 做什么 |
|---|---|---|
| 教师 | 课堂投影演示 | 现场作图并拖动关键点，演示"三角形中位线平行于第三边""圆周角定理"一类命题在全过程中的成立，而不是只展示一张静止的图 |
| 教师 | 备课 | 把演示用图保存为 `.gboard` 文件，下节课直接打开复用；因格式是纯文本 JSON，可在文本编辑器中批量修改坐标与标注说明 |
| 学生 | 课后作业作图 | 按题目要求完成作图（作垂线、角平分线、求交点并标注长度/角度），保存后提交 `.gboard` 文件 |
| 教师 | 批改作业 | 打开学生提交的 `.gboard` 文件，拖动图中的自由点，通过图形与测量值是否保持几何关系判断作图是否正确（若学生用"看起来像"的独立线段冒充垂线，拖动后即会露馅） |
| 教师与学生 | 课堂中途操作 | 用撤销/重做回退误操作，用缩放与平移调整视图范围，用网格与坐标轴辅助定位 |

约束：单次课堂演示不应因图元数量导致明显等待，因此单文件图元规模按几十至几百个设计，上限按 1000 个图元考虑。

## 3. 必须实现的功能

### 3.1 基础作图工具（F1–F8）

| 编号 | 功能 | 验收方式 |
|---|---|---|
| F1 | 独立点：在空白处创建一个不受其他对象约束的自由点 | 选择"点"工具后单击画布坐标 (120, 80)，画布上出现一个点；单击该点使其进入选中状态，状态栏显示其坐标为 (120, 80)，容差 ±1 像素对应的坐标值 |
| F2 | 附着点：在其他对象上创建被约束在该对象上的点 | 选中"点"工具后单击一条已有线段的中部，生成一个落在线段上的点；拖动该点，点只能沿这条线段移动，其到线段两端距离之和保持不变（等于线段长度，容差 0.5 像素） |
| F3 | 线段：依次指定两个端点创建线段 | 依次单击两点创建线段后，测量该线段长度记为 L；拖动任一端点，线段随之伸缩，长度读数同步变化，且两端点位置与鼠标落点一致（容差 2 像素） |
| F4 | 射线：依次指定端点与方向上一点创建射线 | 创建射线后，端点位于单击位置；沿射线方向滚轮缩小视图至 50%，射线仍在一端终止、另一端延伸出可视区域，不出现另一端封口 |
| F5 | 直线：依次指定两个点创建两端无限延伸的直线 | 创建直线后，滚轮缩小视图至 50%，直线两端均延伸出可视区域；拖动其中一个定义点，直线绕另一点旋转，旋转后仍通过两个定义点 |
| F6 | 圆：依次指定圆心与圆上一点创建圆 | 创建圆后，测量其半径记为 R，并测量圆心与圆上给定点的距离；拖动圆上给定点使 R 变化，两个读数始终相等（容差 0.5 像素对应值） |
| F7 | 三点圆弧：依次指定起点、终点与弧上一点创建圆弧 | 依次单击三点创建圆弧；拖动第三个点使弧向另一侧鼓出，弧的起点与终点保持不动，弧线始终通过该点（弧上最近点与该点距离小于 2 像素） |
| F8 | 多边形：按顺序指定 3 个及以上顶点创建闭合多边形 | 依次单击 4 个点并双击结束，得到一个四边形；其边数为 4，面积读数等于按这 4 个顶点坐标用鞋带公式算出的值（容差 0.5%）；顶点数少于 3 时双击结束不生成多边形并给出提示 |

### 3.2 动态几何约束（F9–F15）

| 编号 | 功能 | 验收方式 |
|---|---|---|
| F9 | 中点：对两点或一条线段创建其中点 | 对线段 AB 创建中点后，中点位于 A、B 之间；同时测量 A 到中点与中点到 B 的距离，两读数之差不超过 0.5 像素对应的值；拖动 A，该等式始终成立 |
| F10 | 垂线：过给定点作给定直线的垂线 | 对直线 L 与不在 L 上的点 P 创建垂线，垂线通过 P；用"角度"测量在垂足处测得 90°，拖动 P 或直线的定义点后该读数仍为 90.0°（容差 0.1°） |
| F11 | 平行线：过给定点作给定直线的平行线 | 对直线 L 与点 P 创建平行线；用"角度"测量新直线与 L 被第三条截线所截的同位角，两读数之差不超过 0.1°；拖动 P 后两直线始终无交点（延长至可视区外仍不相交） |
| F12 | 角平分线：对三点（顶点居中）或其确定的角创建角平分线 | 对点 A、顶点 B、点 C 创建角平分线；测量 ∠ABX 与 ∠XBC（X 为平分线上任取一点），两读数之差不超过 0.1°；拖动 A、C 后该关系保持 |
| F13 | 两曲线交点：对两条曲线创建交点 | 作一个圆与一条与该圆相交的直线，创建交点后得到 2 个交点；拖动直线使两者分离，交点消失且状态栏提示"当前无交点"；再拖回相交位置，交点重新出现于正确位置（与解析解偏差小于 1 像素） |
| F14 | 依赖图重算：拖动点时所有依赖对象按依赖关系自动重算 | 构造链 P1 → 线段 S → S 的中点 M → 过 M 的垂线 → 该垂线与另一直线的交点 Q；拖动 P1，线段、中点、垂线、交点全部在 50 ms 内跟随更新（用连续拖动 100 次、测量单帧重算耗时的方式验证），且全部几何关系（中点、垂直）仍成立 |
| F15 | 循环依赖拒绝：不允许建立导致循环依赖的约束 | 对已由 A、B 决定的对象再次施加使 A 反过来依赖该对象的约束，该操作被拒绝，状态栏或对话框给出"该约束会造成循环依赖"的提示，图形状态与操作前一致（图元数不增加） |

### 3.3 测量与标注（F16–F24）

| 编号 | 功能 | 验收方式 |
|---|---|---|
| F16 | 两点距离测量 | 对点 A、B 施加距离测量，画布上出现距离标注；读数与按当前坐标算出的欧氏距离一致（容差 0.5 像素对应值）；拖动 B，读数在 50 ms 内跟随更新 |
| F17 | 线段长度测量 | 对线段施加长度测量，标注显示其长度；拖动任一端点，读数随之变化，且与该线段两端点坐标算出的距离一致（容差 0.5 像素对应值） |
| F18 | 角度测量（三点，顶点居中） | 依次选择点 A、顶点 B、点 C 施加角度测量，标注显示 ∠ABC 的度数；取 A(100,0)、B(0,0)、C(0,100) 的直角情形，读数为 90.0°（容差 0.1°）；拖动 C 越过 180°，读数按 0°–180° 范围连续变化且不出现负值 |
| F19 | 圆半径测量 | 对圆施加半径测量，读数与圆心到圆周的像素距离一致（容差 0.5 像素对应值）；拖动圆上定义点改变半径，读数同步更新 |
| F20 | 圆周长测量 | 对圆施加周长测量，读数等于 2π 乘以同一圆的半径读数（相对误差小于 0.5%）；改变半径后该关系保持 |
| F21 | 圆面积测量 | 对圆施加面积测量，读数等于 π 乘以半径读数平方（相对误差小于 1%）；改变半径后该关系保持 |
| F22 | 多边形面积测量 | 对多边形施加面积测量，读数等于按当前顶点坐标用鞋带公式算出的面积（相对误差小于 1%）；拖动任一顶点改变形状后读数同步更新 |
| F23 | 点坐标标注 | 对点施加坐标标注，标注按当前视图显示该点坐标；拖动该点，标注中的数值在 50 ms 内跟随更新，且与状态栏显示的坐标一致（容差 1 像素对应值） |
| F24 | 测量值实时更新与一致性 | 在含 10 个测量的图形中拖动一个被多个测量依赖的点，全部测量值在同一帧内更新完成并重绘，无任何测量值停留在拖动前数值；连续拖动 5 秒后松手，最终读数与松手位置对应的几何值一致（容差同各测量项） |

### 3.4 文件读写（F25–F32）

| 编号 | 功能 | 验收方式 |
|---|---|---|
| F25 | 新建：清空当前图形建立空白文档 | 在有图形的状态下选择"新建"，画布立即变为空；若当前文档有未保存修改，先弹出询问对话框，选择"取消"则画布保持原样 |
| F26 | 打开：从磁盘读取 `.gboard` 文件 | 打开一个含 20 个图元的文件，画布在 1 秒内完整还原该图形：图元数量、类型、坐标、约束关系、测量标注均与原文件一致 |
| F27 | 保存：将当前图形写回文件 | 保存后重新打开该文件，图形与保存前逐项一致（图元数量、各图元坐标容差 0.001，约束与测量具备且指向同一对象） |
| F28 | 另存为：指定新路径保存并切换当前文件 | 执行"另存为"并指定新文件名，磁盘上出现该文件且内容与"保存"结果一致；窗口标题中的文件名更新为新文件名 |
| F29 | 存储格式：UTF-8 编码的 JSON 文本，可人工查看与编辑 | 用记事本打开 `.gboard` 文件，可见缩进良好的 JSON 文本，含版本字段、图元数组与测量数组等具名字段；用记事本把某个点的坐标数值改成另一合法数值并保存，再次打开后该点出现在改动后的位置 |
| F30 | 版本字段：文件带格式版本号 | 新保存的文件中存在格式版本号字段，其值为当前程序写入的版本；用记事本把该字段改为一个更高的、不支持的版本号后打开，程序拒绝加载并给出明确的"版本不受支持"错误提示，画布不被破坏（保持打开前内容） |
| F31 | 向前兼容读取策略 | 打开一个由较低格式版本生成的文件，程序按既有规则读取并完整还原图形；对文件中无法识别的字段或图元类型，程序给出可定位的提示（含文件名与出错位置），且不崩溃 |
| F32 | 容量与容错上限 | 生成含 1000 个图元（点、线段、圆、多边形、测量混合）的文件并打开，操作成功且界面在 3 秒内可交互；打开一个被截断的或字段缺失的 `.gboard` 文件时，程序给出错误提示且不崩溃（进程仍存活，画布保持打开前内容） |

### 3.5 界面与视图工具（F33–F43）

| 编号 | 功能 | 验收方式 |
|---|---|---|
| F33 | 工具栏切换当前工具 | 工具栏含点、线段、射线、直线、圆、圆弧、多边形及各类约束与测量入口；单击某按钮后该按钮呈按下状态，随后在画布上的单击按该工具语义生效；同一时刻只有一个按钮处于按下状态 |
| F34 | 状态栏显示鼠标坐标 | 鼠标在画布上移动时，状态栏实时显示当前鼠标位置对应的画布坐标，数值随移动连续变化；鼠标移出画布区域后该显示停止更新（保留最后一次数值或显示占位符） |
| F35 | 状态栏显示操作提示 | 每个工具在选中后，状态栏显示该工具的当前步骤提示（如"请选择第一个点"→"请选择第二个点"）；完成一次作图或按 Esc 取消后，提示回到该工具的初始步骤 |
| F36 | 撤销 | 连续执行 5 次作图操作后连续撤销 5 次，图形逐步回退到每一步之前的状态；再撤销时（无更多历史）该项菜单不可用或点击后无任何变化，程序不崩溃 |
| F37 | 重做 | 执行 3 次作图后撤销 3 次，再重做 3 次，图形恢复到撤销前状态；在撤销后执行新的作图操作，重做历史被清空（重做菜单变为不可用） |
| F38 | 滚轮缩放 | 以鼠标位置为锚点向上滚动滚轮，视图放大且该位置对应的画布点在屏幕上基本不动（偏移小于 2 像素）；向下滚动则缩小；连续缩放至上下限后视图不再变化且仍可正常作图 |
| F39 | 中键拖拽平移 | 按住鼠标中键拖动画布，视图随手移动（移动方向与拖拽方向一致、位移量成比例）；松手后视图停在当前位置，图元几何数据不变（缩放与平移只影响显示） |
| F40 | 网格显示开关 | 网格菜单项为可勾选状态；勾选后画布显示规则网格，取消勾选后网格消失；该开关状态在绘制过程中不影响图元坐标数据 |
| F41 | 坐标轴显示开关 | 坐标轴菜单项为可勾选状态；勾选后显示 x、y 轴（含原点标识）；取消勾选后隐藏；开关操作不改变任何图元的坐标 |
| F42 | 对象选中 | 单击某图元使其进入选中状态（有可见的选中标记，如高亮或控制柄）；按住 Ctrl 单击第二个图元可同时选中两个；单击空白处清除选择；状态栏或界面显示当前选中对象的数量 |
| F43 | 删除选中对象 | 选中一个对象后按 Delete 键，该对象从画布消失；若被删除对象是其他对象的依赖来源，其下游对象按既定策略一并删除或使依赖失效并给出提示（策略在 03 阶段确定，此处只要求行为确定且可观察）；删除操作可通过撤销完整恢复 |

## 4. 明确不做

| 编号 | 不做的功能 | 原因 |
|---|---|---|
| N1 | QML / Qt Quick 界面 | 本期界面用 QWidget 与纯 C++ 代码构建；引入 QML 会同时改变构建方式、部署内容与调试路径，与"经典 Windows 原生风格"目标冲突 |
| N2 | Qt 6 | 本机 Qt kit 为 5.12.12，Qt 6 的模块与 API 变更（如 QRegExp、QTextCodec 移除）会带来一轮无收益的移植成本 |
| N3 | CMake 构建 | 本期用 qmake + nmake；两套构建系统并行会产生两份需要同步维护的构建配置 |
| N4 | 非 Windows 平台 | 目标用户是 Windows 教室环境；跨平台需要处理平台相关绘制与字体差异，本期无此需求 |
| N5 | 三维几何 | 需求为平面几何作图与课堂演示；三维会重构数据模型、投影与交互方式，成本量级不同 |
| N6 | 自动定理证明与符号计算 | 需要计算机代数系统级别的能力与独立的验证语义，与"按约束重算并显示"这一目标无关 |
| N7 | 标注计算值参与后续作图（测量值驱动的约束） | 需求确认为"测量用于显示与标注"，未确认其可作为约束输入；该能力会显著改变依赖模型的定义，列入第 9 节待决 |
| N8 | 打印 | 打印机与纸张设置涉及独立的版面与分页逻辑；课堂演示以屏幕投影为主 |
| N9 | 导出图片（PNG / SVG 等） | 本期交付形态不含导出；确需截图时可用系统截屏工具替代；是否纳入下期见第 9 节 |
| N10 | 多文档标签页 | 本期为单文档界面（一次打开一个文件）；标签页会牵动文件状态、撤销栈与窗口标题的生命周期管理 |
| N11 | 多语言翻译文件（.ts / .qm） | 界面语言固定为简体中文，无第二语言的使用者；翻译框架会引入额外的资源与打包步骤 |
| N12 | 安装包制作 | 本期只交付可分发压缩包（见第 8 节）；安装包需要额外的打包工具链、注册表与卸载逻辑 |
| N13 | 脚本、宏与插件系统 | 面向课堂现场作图，无二次开发需求；脚本能力需引入解释执行环境与安全边界 |
| N14 | 在线协作、账号与云端同步 | 需要服务端、账号体系与网络依赖，与单机离线课堂环境不符 |
| N15 | 动画播放、点的轨迹追踪与函数图像绘制 | 属动态几何的进阶能力，需求确认为"拖动重算"；轨迹与函数绘制需要额外采样与绘制策略 |
| N16 | 圆锥曲线作图工具（椭圆、双曲线、抛物线） | 本期基础作图范围为点、线、圆、圆弧、多边形；圆锥曲线会扩展工具集与交点求解分支 |
| N17 | 自定义表达式解析与单位换算 | 测量输出统一为画布坐标单位下的数值，不做单位制转换，也不接受用户输入表达式 |
| N18 | 触屏与手写笔手势 | 目标设备为鼠标键盘的教室 PC；手势支持需要独立的输入事件处理与命中判定调整 |
| N19 | 读取或写入其他几何软件的文件格式 | 自定义 `.gboard` 格式已满足交换需求；兼容第三方格式需按其规范逐项实现并长期跟随其版本变化 |
| N20 | 数据库、历史归档与用户数据统计 | 数据以单文件形式存于用户自选目录，程序不持有集中存储，也不采集使用数据 |

## 5. 数据

| 项 | 内容 |
|---|---|
| 数据来源 | 用户在画布上的鼠标与键盘交互（作图、约束、测量、视图操作）；以及用户打开的既有 `.gboard` 文件 |
| 存储方式 | 自定义单文件格式，扩展名 `.gboard`，内容为 UTF-8 编码的 JSON 文本，纯文本、可人工查看与编辑 |
| 版本字段 | 文件内包含格式版本号字段，由程序写入；读取时校验，遇到不支持的版本明确报错，不尝试猜测解析 |
| 数据内容 | 图元集合（点、线段、射线、直线、圆、圆弧、多边形）、图元间的约束关系与引用、测量与标注及其引用、必要的视图与显示状态 |
| 编码约定 | 文件一律 UTF-8 写出；读取时按 UTF-8 解析，并按 JSON 规范处理非 ASCII 字符 |
| 单文件典型规模 | 课堂演示与作业作图：几十至几百个图元；对应文件体积在数十 KB 量级 |
| 单文件上限 | 按 1000 个图元设计（含其测量与标注），超出上限的文件不保证打开性能 |
| 数据生命周期 | 由用户自行管理：新建、打开、保存、另存为；程序不做自动备份、不做云端同步、不采集任何使用数据 |
| 数据校验 | 打开文件时校验版本号与结构完整性；结构损坏或字段缺失时报错并保持当前画布不被破坏 |

## 6. 环境约束

| 项 | 值 |
|---|---|
| 目标 Windows 版本 | Windows 10 / 11 x64 |
| Qt 版本 | 5.12.12（msvc2017_64 kit，构建于 v141 ABI） |
| 编译器 | MSVC 工具集 14.44.35207（v143，VS2022） |
| Windows SDK | 10.0.26100.0 |
| 架构 | 64 位 |
| 构建方式 | qmake + nmake，独立构建目录（项目内 build-smoke / build-release） |

**已知风险。** Qt 5.12.12 的 msvc2017_64 kit 构建于 v141 ABI，而本机安装的 MSVC 工具集为 v143，二者构成"可构建但有风险"的组合：MSVC 保持向后兼容，通常可正常编译与链接，但可能出现 `/permissive-` 严格模式下的告警，以及 Windows 头文件中的 `min` / `max` 宏与 Qt 或标准库符号冲突（典型表现为编译期宏展开错误，而不是运行期故障）。构建期需留意此类告警并逐条判断是否影响正确性；若出现无法规避的阻塞性冲突，需在 03 阶段评估是否改用 v141 工具集构建。该风险在首次全量构建（build-smoke）时确认。

**编码约束。** 源文件一律保存为 UTF-8 无 BOM；`.pro` 中已加入 `/utf-8` 编译选项，否则 MSVC 会按本地代码页解释中文字符串字面量，导致包含中文的源文件触发 C1075（文件末尾出现意外的内容）一类解析错误。新增源文件时须保持同一编码，不得混入 GBK 或带 BOM 的文件。

## 7. 界面要求

界面采用经典 Windows 原生风格，具体要求如下。

| 项 | 要求 |
|---|---|
| 风格基线 | 使用 Qt 默认的 Windows 原生样式（不设置 Fusion 风格，不加载任何样式表换肤，不使用 QSS） |
| 界面构建方式 | 全部界面用 C++ 代码构建，禁止使用 `.ui` 文件 |
| 布局方式 | 使用 QHBoxLayout、QVBoxLayout、QGridLayout 等布局管理器组织控件，禁止使用绝对坐标与固定控件尺寸定位；窗口缩放时布局自适应 |
| 字体 | 不指定字体族与字号，沿用系统默认字体，随系统 DPI 与用户设置变化 |
| 颜色 | 不硬编码颜色值，界面配色取自控件的 `palette()`；图元自身的绘制颜色除外（其取值须集中定义，不得散落在绘制代码中） |
| 图标按钮 | 所有图标按钮必须同时设置 `toolTip` 与 `accessibleName`，使鼠标悬停可读、辅助技术可读 |
| 键盘可达性 | 所有可交互控件必须可通过 Tab 键到达；菜单项显示快捷键提示；提供键盘快捷键完成新建、打开、保存、撤销、重做、删除等常用操作 |
| 窗口 | 主窗口包含菜单栏（文件、编辑、视图、帮助分组）、工具栏、画布区域与状态栏；窗口标题显示当前文件名与未保存状态 |
| 状态反馈 | 状态栏左侧显示当前工具与操作提示，右侧显示鼠标画布坐标；错误与确认信息用标准对话框呈现，文案为简体中文 |
| 缩放适配 | 在 Windows 显示缩放为 100%、150% 时，界面文字与控件不重叠、不被裁切 |

## 8. 交付形态

- **源码**：完整工程（`.pro` 文件、`src/` 分层目录、`resources/`、`docs/`），可依据构建说明从零复现构建。
- **可分发运行目录**：Release 构建产物 `GeoBoard.exe`，与 `windeployqt` 收集的运行期依赖一并放入 `dist/` 目录；`dist/platforms/` 必须包含平台插件，否则程序无法启动。
- **分发方式**：将 `dist/` 目录整体压缩为 zip 交付，解压后双击可执行文件即可运行，目标机无需预装 Qt。
- **本期不做安装包**（见 N12）：无安装向导、无注册表写入、无卸载项、无自动更新。
- 运行环境说明与构建步骤随源码以文档形式提供。
