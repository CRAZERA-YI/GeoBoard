GeoBoard 0.1.0 —— 运行说明（给使用者）
=====================================

一、这是什么
------------
一个动态几何画板。用点、线段、直线、圆、圆弧、多边形作图，并可以作出中点、垂线、
平行线、角平分线、两曲线的交点，以及距离、长度、角度、半径、面积的测量标注。

它的关键在于：图形之间记录的是**几何关系**而不是画好的线条。所以拖动任意一个自由点时，
依赖它的图形会按几何关系自动跟着变——比如拖动圆的圆心，圆上所有的点、由这些点决定的
线段与交点都会一起动。

二、运行步骤
------------
1. 把 GeoBoard-0.1.0-win64 整个文件夹解压到任意位置（例如桌面或 D:\GeoBoard）。
   不要只把 GeoBoard.exe 单独拿出来——它必须和同目录下的 DLL 以及 platforms
   子目录放在一起。
2. 双击 GeoBoard.exe。
3. 想立刻看到效果，可以在命令行里执行：GeoBoard.exe --demo
   它会载入一个演示图形（圆 + 两端贴在圆上的线段 + 交点 + 中点 + 三个标注）。
   用"选择"工具拖动圆上的点或圆心，就能看到依赖图形实时跟随。

三、基本用法
------------
* 工具栏左上角的"选择"工具用于选中与拖动，其余按钮是作图工具。
* 作图提示显示在窗口底部状态栏。多数工具"点几下就成"：线段点两下；
  圆先点圆心、再点圆上一点；圆弧点三下（起点、弧上一点、终点）。
* 多边形：依次点击各顶点，**双击**结束绘制（至少 3 个顶点）。
* 垂线 / 平行线：先点作为基准的线，再点垂线 / 平行线要经过的点。
* 交点：依次点两条曲线，它们的交点会被一次全部创建。
* 想用已经画好的点？直接点在它上面即可复用，不必重新画一个。
* 操作失误按 Esc 取消当前未完成的作图。
* Ctrl+Z 撤销，Ctrl+Y 重做，Delete 删除选中的图元。
  删除一个图元时，依赖它的图元会被一并删除，状态栏会告诉你删了几个，可以撤销。
* 滚轮以鼠标位置为中心缩放；按住鼠标中键拖动可平移视图。
* 视图菜单可以关掉网格、坐标轴、点名与标注；"缩放到全部内容"可把图形摆回视野中央。
* 文件菜单保存为 .gboard 文件。它是文本格式，可以用记事本打开查看。

四、常见问题
------------
Q: 双击没反应？
A: 请确认解压完整。GeoBoard.exe 同目录下应当有 Qt5Core.dll、Qt5Gui.dll、
   Qt5Widgets.dll 以及 platforms 文件夹。若提示缺少 vcruntime140.dll，
   请运行 vc_runtime\vcredist_msvc2019_x64.exe 安装微软运行库。

Q: 提示 "This application failed to start because no Qt platform plugin
   could be initialized"？
A: 说明解压不完整——platforms 子目录（其中要有 qwindows.dll）没有被解压出来。
   请重新完整解压压缩包，不要只复制 exe。

Q: 我画的图形不见了？
A: 两种可能：
   ① 视图被缩放或平移到别处了，用"视图 → 缩放到全部内容"（Ctrl+Shift+F）找回来；
   ② 该图形当前处于退化状态（例如三点连成一条直线时圆弧不存在、两条线暂时没有交点）。
      把它拖动回正常位置就会自动恢复——图元并没有被删除。

Q: 为什么中点、交点拖动不了？
A: 它们的位置完全由定义它们的图形决定（中点取决于两个端点，交点取决于两条曲线），
   所以只能拖动决定它的那些点。

Q: 标注的位置没有跟着图形走。
A: 这是本版本的已知缺陷（见 docs/delivery.md 的缺陷 T1）。重新做一个标注即可。

五、系统要求
------------
* Windows 10 / 11（64 位）
* 无需安装 Qt；MSVC 运行库已随包提供
* 不需要管理员权限
